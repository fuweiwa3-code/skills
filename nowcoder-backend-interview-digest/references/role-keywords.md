## Exclude By Default

Exclude unless the user asks otherwise or the post clearly contains backend/platform questions:

- 前端
- 客户端
- Android
- iOS
- 测试
- 测试开发
- 产品
- 运营
- HR
- 算法工程师 with only model/algorithm research questions
- 内容运营
- 设计

## Ambiguous Cases

- `AI应用开发` can be included when questions involve backend services, RAG, Agent, API limits, SSE, FastAPI, Redis, database, or system design.
- `平台开发` should be included when it asks infrastructure, backend workflow, services, data, scheduling, or high concurrency.
- `算法工程师` should be excluded unless the body is clearly about backend/Agent platform implementation.
