Use this text format for the final Feishu message.

```text
【牛客大厂后端面经复习清单】

本次筛选：{post_count} 篇帖子 / {question_count} 个问题
公司范围：阿里、腾讯、字节、百度、美团、京东、拼多多、快手、网易、小米、蚂蚁
方向：后端 / 后台 / AI后端 / Agent开发 / 平台开发

1. {公司}｜{岗位或方向}｜{轮次}
面试时间：{面试时间；若无则写“未注明，帖子发布于 ...”}
来源：{url}

Q1：{问题}
考察点：{tag1}、{tag2}、{tag3}

Q2：{问题}
考察点：{tag1}、{tag2}、{tag3}

Q3：{问题}
考察点：{tag1}、{tag2}、{tag3}

2. ...
```

## Style

- Keep the message compact enough to read in Feishu.
- Prefer one-line questions unless constraints require a second line.
- Do not include long original paragraphs.
- Include source links for traceability.
- If the message exceeds Feishu text limits or becomes hard to scan, split by post.
